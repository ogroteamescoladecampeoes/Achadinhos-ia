# Achadinhos IA — PWA Mobile 1.0

Esta versão foi redesenhada para celular como Progressive Web App (PWA).

Inclui:
- interface mobile-first;
- navegação inferior estilo app;
- dashboard;
- achadinhos;
- geração de Stories;
- resultados;
- configurações;
- manifest PWA;
- service worker;
- prompt de instalação quando hospedado em HTTPS.

## Importante
Esta é a interface PWA inicial. A conexão real com Meta, fontes de afiliados, IA e banco online ainda serão integradas.

Hospedar a PWA em HTTPS e depois configurar backend/banco e OAuth oficial da Meta.
